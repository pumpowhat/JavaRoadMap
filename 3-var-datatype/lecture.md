# Bài 3: Biến và kiểu dữ liệu

## 1. Khai báo biến

<datatype> <name> = <value>

int age = 25

## 2. Kiểu dữ liệu

### a. Kiểu nguyên thủy

| Kiểu    | Kích thước | Giá trị mặc định |
|---------|------------|------------------|
| byte    | 1 byte     | 0                |
| short   | 2 bytes    | 0                |
| int     | 4 bytes    | 0                |
| long    | 8 bytes    | 0L               |
| float   | 4 bytes    | 0.0f             |
| double  | 8 bytes    | 0.0d             |
| char    | 2 bytes    | '\\u0000'        |
| boolean | 1 bit      | false            |

### b. Kiểu tham chiếu

- String
- Array (Mảng)
- Class
- Interface
- Object
- Collection (list,set,map)

## 3. Literal (hằng giá trị)

- Số nguyên: 25, -10, 0
- Số thực: 3.14, -0.5f
- Ký tự: 'A','z','\n'
- Chuỗi: "Hello java"
- Boolean: true, false

## 4. Quy tắc đặt tên biến

- Phải bắt đầu bằng chữ cái hoặc dấu $ hoặc _
- Có thể chứa chux cái, chữ số _ và $
- Phân biệt hoa thường
- Không đặt trùng từ khóa
