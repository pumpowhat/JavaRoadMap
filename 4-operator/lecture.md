# Bài 4 Toán tử ép kiểu

## 1. Toán tử số học

+ - * / % ++ --

## 2. Toán tử quan hệ

==; != ; < ; > ; >= ; <=

## 3. Toán tử logic

- AND : &&
- OR : ||
- NOT: !

## 4. Toán tử gán
=; +=; -=; *=; /=; %=

## 5. Toán tử một ngôi
++ --

## 6. Ép kiểu

### a. Ngầm định

```java
int a = 10;
double b = a // int --> double
```

### b. Tường minh

```java
double x = 25.75
int y = (int) x // double --> int
```
